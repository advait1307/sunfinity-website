# Sunfinity website

Official marketing site for Sunfinity Technology Solutions (Vite + React).

## Develop

```bash
npm install
npm run dev
```

## Careers CMS (Sanity)

Open roles are managed in Sanity so 3–4 people can add jobs without touching code.

- Setup guide: [docs/CAREERS_SANITY.md](docs/CAREERS_SANITY.md)
- Local Studio: `npm run studio`
- Detail pages: `/careers/:slug`

Until `.env` has a Sanity project ID, the site serves a local sample job.

## Build

```bash
npm run build
```
